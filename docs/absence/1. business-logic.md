# Business Logic: Absence Staff Sessions & Action

## Service Name: AbsenceService
## Use Case: Get Sessions API

## Status
- Request Active = Request status 'approve' or 'active' & session is open
- Log Start Open = (Log Start status is 1) & (Log Start session is open)
- Log End Open = (Log End status is 1) & (Log End session is open)
- Log Open = Log Start Open or Log End Open
- Log Active = (Log Start status is done/0) & (Log End status is pending/1) & (Log End session is locked)
- Log Closed = Log Start & Log End status = 0
- Log Expired = Log Start & Log End both session is expired & status is 1
- Log Active Expired = (Log Start status is done/0) & (Log End status is pending/1) & (Log End session is expired)

## Note
- current date not static (fix model & filter trait)

1. Input (class construct (Staff ID))

2. Init Class Variable (staff, menu, data, presenceStatus = ON and etc)

3. Process Flow (getMenu())
- Set Staff Attribute (reguler/shift) & Condition (geofenceoff ON/OFF, etc)
- Check If Leave => Output
- Else Check If Permission => Output
- Else Check If Duty => Output
- Else Check If Dispense => Output
- Else Check If Extra Old End Open => Output
- Else Check If Holiday
    - Check If Extra on Holiday => Output
- Else
    - Check If Presence Empty => Create Absence & Log
    - Check If Presence Open => Output
    - Check If Presence Active
        - Check If Break => Output
        - Check If Visit => Output
        - Check If Excuse => Output
    - Check If Presence Closed
        - Check If Extra on Presence Closed => Output

3. Output (sendResponse())
- Success => Send Response Menu
- Failure => Return false
- json object : 
    {
        "status": "success",
        "message": "",
        "menu": ["leave","reguler"],
        "staff": {
                "type": "reguler",
                "geofence_off": "on",
                "coordinate": {}
        },
        "data": [
            "reguler": {
                "id": 2,
                "status": "active",
            },
            "extra": {
                "id": 2,
                "status": "active",
            },
        ]
    }

4. Helpers
    1. Check Leave (isLeave())
    - Check if Request Active (category 'leave' status is 'approve' or 'active', if type 'sick' filter by date start, if 'other' filter by date currently)
        - if success => push menu 'leave', data.leave = Request Active, presenceStatus = OFF, return true
        - else return false
    *note : 
    - frontend
        - if in menu=='leave' && data.leave.type=='sick' => Akhiri Cuti
        - if in menu=='leave' && data.leave.type!='sick' => Anda Masih Cuti

    2. Check Permission (isPermission())
    - Check if Request Active (category 'permission' status is 'approve' or 'active', if type 'sick' filter by date start, if 'other' filter by date currently)
        - if success => push menu 'permission', data.permission = Request Active, presenceStatus = OFF, return true
        - else return false
    *note : 
    - frontend
        - if in menu=='permission' && data.permission.type=='sick' => Akhiri Izin or Tambah Tanggal Sakit
        - if in menu=='permission' && data.permission.type!='sick' => Anda Masih Izin

    3. Check Duty (isDuty())
    - Check if Request Active (category 'duty' status is 'approve' or 'active' filter by date currently)
        - if success => push menu 'duty', data.duty = Request Active, data.dutyLog = Log Open Related order by id asc, presenceStatus = OFF, return true
        - else return false
    *note : 
    - frontend
        - if in menu=='duty' && data.dutyLog.category.queue==2 => Absen Dinas Luar (Selesai)
        - if in menu=='duty' && data.dutyLog.category.queue==1 => Absen Dinas Luar (Mulai)

    4. Check Extra Old Active (isExtraOld())
    - Check if Log Active Expired
        - if success => push menu 'extra', data.extra = Request Related, data.extraLog = Log Active Expired, staff.geofenceOff = Request Related type == outside ? ON:OFF, return true
        - else return false
    *note : 
    - frontend
        - if in menu=='extra' && data.extraLog => Absen Lembur (Selesai)
        - if in menu=='extra' && !data.extraLog => Absen Lembur (Mulai)

    5. Check Holiday (isHoliday())
    - Check if Holiday Active (by staff work type)
        - if success => presenceStatus = OFF, return true
        - else return false

    6. Check Extra on Holiday (isExtraHoliday())
    - Check if Request Active & Check if Holiday Active
        - if success => push menu 'extra', data.extra = Request Active, data.extraLog = Log Open Related  order by id asc, staff.geofenceOff = Request Active type == outside ? ON:OFF, return true
        - else return false
    *note : 
    - frontend
        - if in menu=='extra' && data.extraLog.category.queue==2 => Absen Dinas Luar (Selesai)
        - if in menu=='extra' && data.extraLog.category.queue==1 => Absen Dinas Luar (Mulai)

    7. Check Presence Empty (isPresenceEmpty)
    - Check if Log Empty & presenceStatus is ON
        - if success => Create Absence & Log (by staff work type)
        - return true

    8. Check Presence Open (isPresenceOpen)
    - Check if Log Open
        - if success => push menu 'presence', data.presenceLog = Log Open order by id asc, return true
        - else return false

    9. Check Presence Active (isPresenceActive)
    - Check if Log Active
        - if success => return true
        - else return false

    10. Check Break (isBreak)
    - Check If Log Open & Presence Active
        - if success => push menu 'break', data.breakLog = Log Open order by id asc, return true
        - else return false

    11. Check Visit (isVisit())
    - Check if Request Active & Presence Active
        - if success => push menu 'visit', data.visit = Request Active, data.visitLog = Log Open Related order by id asc, data.inVisit = Visit (table), return true
        - else return false
    *note : 
    - frontend
        - if in menu=='visit' && data.inVisit && data.visitLog.category.queue==2 => Absen Dinas Dalam (Selesai)
        - if in menu=='visit' && data.inVisit && !data.visitLog => Bukti Dinas Dalam
        - if in menu=='visit' && !data.inVisit && data.visitLog.category.queue==1 => Absen Dinas Dalam (Mulai)

    12. Check Excuse (isExcuse())
    - Check if Request Active & Presence Active
        - if success => push menu 'excuse', data.excuse = Request Active, data.excuseLog = Log Open Related order by id asc, return true
        - else return false
    *note : 
    - frontend
        - if in menu=='excuse' && data.excuseLog => Absen Dinas Dalam (Selesai)
        - if in menu=='excuse' && !data.excuseLog => Absen Dinas Dalam (Mulai)

    13. Check Presence Closed (isPresenceClosed)
    - Check if Log Closed
        - if success => return true
        - else return false

    14. Check Extra on Presence Closed (isExtraPresenceClosed())
    - Check if Request Active & Check if Presence Closed
        - if success => push menu 'extra', data.extra = Request Active, data.extraLog = Log Open Related order by id asc, staff.geofenceOff = Request Active type == outside ? ON:OFF, return true
        - else return false
    *note : 
    - overnight pass status pending
    - frontend
        - if in menu=='extra' && data.extraLog.category.queue==2 => Absen Dinas Luar (Selesai)
        - if in menu=='extra' && data.extraLog.category.queue==1 => Absen Dinas Luar (Mulai)
